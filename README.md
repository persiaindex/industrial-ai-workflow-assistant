# Industrial AI Workflow Assistant

A production-oriented AI application for industrial document intelligence, maintenance support, and workflow automation.

## Overview

Industrial AI Workflow Assistant helps users query technical and industrial documents, retrieve grounded answers, and generate maintenance-oriented action plans using retrieval-augmented generation, structured outputs, FastAPI, and tool-based workflow automation.

The project is designed as a professional AI engineering portfolio project. It focuses on practical software architecture, reliable document retrieval, evaluation, deployment readiness, and responsible AI principles.

## Problem Statement

Industrial teams often work with manuals, safety instructions, maintenance notes, inspection checklists, and machine error-code documents. Important information may be distributed across many files, making it difficult to quickly find reliable answers.

This project demonstrates how an AI assistant can support this workflow by:

- loading and processing industrial documents
- splitting documents into searchable chunks
- retrieving relevant information
- generating grounded answers with source references
- supporting maintenance-oriented workflow automation
- exposing the system through a FastAPI backend
- testing and evaluating the system behavior
